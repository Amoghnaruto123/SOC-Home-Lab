## **Investigation summary**



A controlled failed-login attempt was performed against the temporary wazuh\_lab account on the Windows endpoint. Windows generated Security Event ID 4625, which was collected by the Wazuh agent.

Wazuh matched the event against built-in rule 60122 and triggered custom rule 100102, generating a level 8 alert.

The event was caused by an intentional incorrect password during testing. It does not indicate a confirmed malicious login attempt.



### \## Response Actions



1\. Reviewed the Wazuh alert generated by custom rule 100102.

2\. Verified Windows Security Event ID 4625.

3\. Identified the affected account as wazuh\_lab.

4\. Confirmed the failure was caused by an incorrect password.

5\. Classified the event as a benign, controlled lab simulation.

6\. Removed the temporary test account after testing.



#### \## Final Outcome



The Wazuh detection successfully identified and

generated an alert for the simulated failed login.

No malicious activity was confirmed.
