# Incident Investigation: Failed Windows Login

> **Environment:** Controlled SOC home-lab simulation  
> **Platform:** Windows endpoint monitored by Wazuh

## 1. Incident Overview

A controlled failed-login attempt was generated on the Windows endpoint using a temporary test account. The attempt used an incorrect password and produced Windows Security Event ID `4625`.

Wazuh collected the event and matched it against the built-in detection rule `60122`. The custom rule `100102` then generated a **Level 8** alert.

## 2. Event Details

| Field | Value |
|---|---|
| Incident Type | Failed authentication |
| Severity | Level 8 — Custom Wazuh Rule |
| Windows Event ID | `4625` |
| Custom Wazuh Rule ID | `100102` |
| Built-in Wazuh Rule | `60122` |
| Affected Account | `wazuh_lab` |
| Host | `DESKTOP-AF7NJD2` |
| Logon Type | `3` — Network |
| Authentication | NTLM |
| Failure Reason | Incorrect password |
| Source Address | `::1` (localhost) |
| Detection Status | Successfully detected |
| Classification | Benign test event |

## 3. Investigation Summary

The failed-login attempt was intentionally performed as part of the lab. Windows recorded the event as Security Event ID `4625`, and the Wazuh agent forwarded it to the manager.

The event matched built-in rule `60122`, which enabled the custom rule `100102` to generate a Level 8 alert. The alert was reviewed in the Wazuh dashboard, and the event details were checked to confirm the account, host, logon type, authentication method, and failure reason.

Because the attempt was deliberately generated with an incorrect password during testing, it was classified as a **benign lab event**, not a confirmed malicious login attempt.

## 4. Response Actions

1. Reviewed the Wazuh alert generated by custom rule `100102`.
2. Verified the corresponding Windows Security Event ID `4625`.
3. Identified the affected account as `wazuh_lab`.
4. Confirmed that the failure reason was an incorrect password.
5. Classified the event as a benign, controlled lab simulation.
6. Removed the temporary test account after testing.

## 5. Final Outcome

The custom Wazuh rule successfully detected the simulated failed login and generated a Level 8 alert. The event was investigated and documented as an intentional test. No malicious activity was confirmed.
